# 🛡️ Cyber-Security-And-Ethical-Hacking-Roadmap-

> An interactive, browser-based 12-week study planner designed for beginners exploring the fundamentals of cybersecurity, defensive ops (Blue Team), and ethical hacking.

---

## 📌 Overview

Navigating the vast field of cybersecurity can be overwhelming for beginners. **Cybersecurity Roadmap** simplifies this journey by breaking down key learning domains into a structured, step-by-step 12-week plan. 

Whether you're leaning toward **Blue Team** (defensive analysis, logging, incident response) or **Ethical Hacking** (offensive security, penetration testing fundamentals), this tool helps you stay consistent, complete hands-on tasks, and monitor your learning growth over time.

---

## ✨ Features

- 🗓️ **12-Week Structured Curriculum:** A balanced path covering core networking, OS security, traffic analysis, Web/App security, and defense fundamentals.
- 🎯 **Hands-on Action Items:** Clear weekly tasks, recommended free learning platforms, and industry-standard entry-level certifications (e.g., CompTIA Security+, EJPT).
- ✅ **Interactive Progress Tracker:** Check off completed tasks and watch your overall progress bar update in real time.
- 💾 **Persistent Local Storage:** Built-in browser persistence so your progress stays saved without needing an account or external database.
- 🎨 **Responsive UI:** Modern design crafted with raw HTML, CSS, and vanilla JavaScript—lightweight, fast, and accessible on both desktop and mobile.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structure and accessible UI elements.
- **CSS3:** Custom styles, modern layout design (Flexbox/Grid), and smooth progress visualizers.
- **JavaScript (ES6+):** Dynamic task management, DOM updates, and `localStorage` persistence.
